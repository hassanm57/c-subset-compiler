# Full compiler for C (subset of language)

# Components

- Lexical	Analyzer	(tokenization)
• Syntax	Analyzer	(parser	based	on	defined	grammar)
• Semantic	Analysis	(type	checking,	scope	handling)
• Intermediate	Representation	(e.g.,	Three	Address	Code)
- Array Support
- Optimization Pipeline (Constant Folding, Dead Code Elim, Constant Prop)
- Returns Error description along with line number

# Tools
- Flex, Bison, MinGW, WinFlexBison


Has test cases to test on.
